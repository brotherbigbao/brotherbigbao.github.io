# ubuntu 禁止用户执行任何命令
> 禁止用户执行任何命令

# 设置用户默认bash

/etc/passwd

```
/bin/bash 改成 /bin/rbash
```

# 更改$PATH

在 /home/yourname/.profile中追加下面这行：

```
export PATH="/home/yourname"
```

# 修改 /home/yourname 下文件权限

```
chmod 444 .profile
chmod 444 .bashrc
```

# deepseek 给出更好的方案

```
# 1. 设置rbash
sudo usermod -s /bin/rbash username

# 2. 限制PATH
sudo mkdir -p /home/username/.restricted_bin
sudo ln -s /bin/ls /home/username/.restricted_bin/  # 只允许特定命令
sudo chown -R root:root /home/username

# 3. 设置用户的.profile
sudo bash -c 'cat > /home/username/.profile << EOF
export PATH=/home/username/.restricted_bin
readonly PATH
readonly HISTFILE
alias exit="echo \"Not allowed to exit\""
alias logout="echo \"Not allowed to logout\""
EOF'

# 4. 设置文件权限为只读
sudo chmod 444 /home/username/.profile
```
